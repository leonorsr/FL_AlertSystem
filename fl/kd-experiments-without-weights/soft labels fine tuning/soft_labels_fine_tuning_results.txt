Soft Labels Fine Tuning Results
===============================

Objective
---------
Improve local training without exchanging model weights. Candidate selection prioritizes
local PR-AUC, then global test PR-AUC, local F1 and global test F1.

Search setup
------------
- Experiments: exp11_baseline_final, exp12_final_unweighted, exp13_final_keep_best_local, exp14_final_clustered
- Search runs per candidate: 1
- Search global rounds: 3
- Search local epochs: 20
- Communication mode: soft_labels
- Communicates model weights: no

Validation note
---------------
The complete exploratory grid below used one lightweight run per candidate. A follow-up
matched-seed comparison completed for exp11_baseline_final and confirmed the same selected
candidate (c2_local_hard_label_focus). The matched-seed rerun stalled during exp12 startup,
so its partial artifacts are excluded from the rankings below. The runner now uses matched
seeds across candidates for future validation runs.

Candidates
----------
- c1_current_baseline: Current soft-label configuration used as the reference.
  alpha=0.50, temperature=2.00, learning_rate=0.000800, dropout=0.30
- c2_local_hard_label_focus: Give more weight to local hard labels while preserving the global soft-label signal.
  alpha=0.75, temperature=2.00, learning_rate=0.000800, dropout=0.30
- c3_local_lower_dropout: Prioritize local fitting with stronger hard-label weight and lower dropout.
  alpha=0.75, temperature=2.00, learning_rate=0.000800, dropout=0.20
- c4_balanced_lower_lr: Use a moderate local bias with lower learning rate and a softer temperature.
  alpha=0.65, temperature=1.50, learning_rate=0.000500, dropout=0.20
